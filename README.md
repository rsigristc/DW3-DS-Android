# DW3-DS-Android

El código fuente de la POC vive en `dw2003-dual-screen/`. La versión **0.7.4** abre la pestaña Mapa del juego (START + L1×2) y, al elegir un destino, cierra el menú para disparar la carga de Flawe.

APK de prueba: [DW2003-Dual-Screen-v0.7.4-poc-debug.apk](https://github.com/rsigristc/DW3-DS-Android/releases/tag/v0.7.4-poc).
