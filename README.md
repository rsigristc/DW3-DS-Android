# DW3-DS-Android

El código fuente de la POC vive en `dw2003-dual-screen/`. La versión **0.7.3** corrige el silencio al reanudar, limita el viaje rápido a destinos visitados y permite abrir el mapa del juego desde el radar.

APK de prueba: [DW2003-Dual-Screen-v0.7.3-poc-debug.apk](https://github.com/rsigristc/DW3-DS-Android/releases/tag/v0.7.3-poc).
