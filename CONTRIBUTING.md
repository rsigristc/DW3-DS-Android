# Contributing

Bug reports, device results, documentation fixes and code changes are welcome.

## Before opening a change

1. Read `README.md`, `NOTICE` and `docs/BUILDING.md`.
2. Keep application code in `dw2003-dual-screen/app/`.
3. Do not commit APKs, keystores, passwords, ROM images, BIOS files or Memory Cards.
4. Run the same entry point CI uses:

   ```bash
   ./scripts/build.sh
   ```

5. Describe what you changed and which device or emulator you used.

Contributions are accepted under GPL-3.0-or-later. By submitting a change you
confirm that you have the right to provide it under those terms.

Do not paste secrets, BIOS dumps or ROM files into a public issue. For a
security-sensitive report, open a short issue asking for a private channel.
